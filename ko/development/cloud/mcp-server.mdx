<Warning>
  **클로즈드 베타 — 초대 전용입니다.** Comfy Cloud MCP는 현재 사용자별 기능 플래그 제어를 통해 클로즈드 베타 상태입니다. 프로젝트가 발전함에 따라 기능, 도구 및 동작이 변경될 수 있습니다. 아직 접근 권한이 없다면 [대기 리스트에 등록하세요](https://form.typeform.com/to/hHmvw1UH).
</Warning>

Comfy Cloud MCP는 [Model Context Protocol(MCP)](https://modelcontextprotocol.io)을 통해 Claude Desktop, Claude Code, Cursor, Amp를 비롯한 AI 어시스턴트들을 [Comfy Cloud](https://cloud.comfy.org)에 연결합니다. 이를 통해 AI 에이전트는 이미지, 비디오, 오디오 및 3D 콘텐츠를 생성하고, 모델과 노드를 검색하며, 로컬 GPU 없이 클라우드 GPU에서 전체 ComfyUI 워크플로우를 실행할 수 있습니다.

## 빠른 시작

**시작하기 전에 다음 사항을 확인하세요:**

- 활성화된 **Comfy Cloud 구독**(워크플로우 제출에 필요)
- 이메일이 **클로즈드 베타**용으로 설정되어야 합니다(위 참고사항 참조)
- 로그인 방법: **OAuth**(지원되는 경우 권장) 또는 **Comfy API 키**(comfyui-…)

### OAuth 또는 API 키로 로그인하기

**OAuth (붙여넣을 API 키 없음)** — **Claude Code** 또는 **Claude Desktop**에서 원격 서버 `https://cloud.comfy.org/mcp`를 추가하고 클라이언트의 **Authenticate** 컨트롤을 사용해 Comfy 계정으로 로그인하세요. 파트너 생성 및 워크플로우는 연결 후 동일한 도구를 사용합니다.

**API 키** — 여전히 완벽히 지원됩니다. 클라이언트가 OAuth를 제공하지 않거나 키를 선호하는 경우 아래의 원클릭 설치 또는 수동 설정을 사용하세요.

<Warning>
  **OAuth 롤아웃.** MCP 서버는 이미 프로덕션 환경에서 OAuth를 수락하지만, 모든 사용자가 엔드투엔드로 로그인이 가능해지려면 다음 Comfy Cloud 프로덕션 배포가 완료될 때까지 기다려야 합니다(디스커버리 엔드포인트가 따라잡아야 함). OAuth가 작동하기 전까지는 API 키를 사용하세요—기존 API 키 설정은 변경되지 않습니다.
</Warning>

API 키를 사용하고 아직 키가 없다면, 다음 가이드를 참고해 키를 받으세요:

### 설치 및 연결(API 키 사용)

원클릭 설치 프로그램은 MCP 클라이언트(Claude Code, Cursor, Amp)를 감지하고 Comfy API 키를 요청한 뒤 원격 MCP 서버를 구성합니다—Node.js나 기타 종속성은 필요하지 않습니다.

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/Comfy-Org/comfy-cloud-mcp/main/install.sh | bash
    ```
  </Tab>

  <Tab title="Windows (PowerShell)">
    ```powershell
    irm https://raw.githubusercontent.com/Comfy-Org/comfy-cloud-mcp/main/install.ps1 | iex
    ```
  </Tab>
</Tabs>

### API 키를 이용한 수동 설정

Comfy Cloud MCP는 `https://cloud.comfy.org/mcp`에 호스팅됩니다. MCP 클라이언트를 해당 URL로 지정하고 API 키를 입력하세요:

<Tabs>
  <Tab title="Claude Code">
    ```bash
    claude mcp add comfyui-cloud \
      --transport http \
      https://cloud.comfy.org/mcp \
      -H "X-API-Key: your-api-key-here"
    ```
  </Tab>

  <Tab title="Claude Desktop">
    다음 내용을 Claude Desktop 구성 파일에 추가하세요:

    | OS | 구성 경로 |
    |:---|:------------|
    | macOS | `~/Library/Application Support/Claude/claude_desktop_config.json` |
    | Windows | `%APPDATA%\Claude\claude_desktop_config.json` |
    | Linux | `~/.config/Claude/claude_desktop_config.json` |

    ```json
    {
      "mcpServers": {
        "comfyui-cloud": {
          "url": "https://cloud.comfy.org/mcp",
          "headers": {
            "X-API-Key": "your-api-key-here"
          }
        }
      }
    }
    ```
  </Tab>

  <Tab title="Cursor">
    다음 내용을 Cursor MCP 구성 파일(.cursor/mcp.json)에 추가하세요:

    ```json
    {
      "mcpServers": {
        "comfyui-cloud": {
          "url": "https://cloud.comfy.org/mcp",
          "headers": {
            "X-API-Key": "your-api-key-here"
          }
        }
      }
    }
    ```

    자세한 내용은 [Cursor의 MCP 문서](https://docs.cursor.com/context/model-context-protocol)를 참조하세요.
  </Tab>
</Tabs>

  서버를 추가한 후 MCP 클라이언트를 재시작하여 새 설정을 적용하세요.

## 사용법

**간단히 요청하세요.** 에이전트가 스스로 적합한 도구를 선택합니다— *"우주 속 고양이 우주비행사 생성"*, *"SDXL 체크포인트 찾기"*, *"이것을 고화질로 업스케일"*

### 생성 경로 안내

에이전트는 두 가지 경로 중 하나를 선택합니다:

| 경로 | 도구 | 최적의 용도 |
|:-----|:-----|:---------|
| **파트너 API** | `partner_generate` | 명명된 제공업체(Flux, Grok, Nano Banana, Ideogram, GPT-image, Seedream 등) |
| **맞춤형 워크플로우** | `submit_workflow` | 오픈소스 모델, LoRA/ControlNet, 다단계 그래프, 또는 `partner_generate`에서 처리되지 않는 모든 것 |

파트너 제공업체의 경우, `partner_generate`는 **무조건 먼저 실제 Comfy Cloud 워크플로우를 실행**합니다. 결과는 워크플로우가 내장된 자산 라이브러리에 저장되며, 편집기에서 다시 열 수 있습니다. 도구는 `prompt_id`를 반환하므로 `get_job_status`로 상태를 조회한 뒤 `get_output`으로 다운로드하세요(다른 워크플로우와 동일).

이미지 입력 요청이나 아직 저장 가능한 모델이 아닌 경우, 서버는 **자동으로 기본적으로 파트너 프록시 응답으로 돌아가며 즉시 다운로드 URL을 제공**합니다. 이 백업 경로는 내부적인 것이며, 사용자가 선택하거나 해제할 수 없습니다. 이러한 직접 결과는 **자산 라이브러리에 저장되지 않습니다.**

## 사용 가능한 도구

### 워크플로우 실행

| 도구 | 설명 |
|:-----|:------------|
| `submit_workflow` | ComfyUI API 형식의 워크플로우를 Comfy Cloud에서 실행하도록 제출 |
| `get_job_status` | 제출된 워크플로우의 실행 상태 조회 |
| `get_output` | 완료된 워크플로우의 이미지, 비디오 또는 오디오 출력 가져오기 |
| `cancel_job` | 보류 중이거나 실행 중인 작업 취소 |
| `get_queue` | 실행 중인 작업과 보류 중인 작업 수 확인 |

### 파트너 API 생성

| 도구 | 설명 |
|:-----|:------------|
| `partner_generate` | 파트너 API(Flux, Nano Banana, Grok, GPT-image, Ideogram, Seedream 등)로 생성. 기본적으로 Comfy Cloud 워크플로우를 통해 실행; `prompt_id`를 반환하고 자산 라이브러리에 저장. `get_job_status`/`get_output`로 다른 워크플로우와 동일하게 조회. 지원되지 않는 경우 자동으로 즉시 프록시 URL로 돌아갑니다. |

### 디스커버리

| 도구 | 설명 |
|:-----|:------------|
| `search_templates` | [comfy.org](https://comfy.org/workflows)에서 미리 만들어진 워크플로우 템플릿을 텍스트, 태그, 미디어 유형 또는 모델별로 검색 |
| `search_models` | 텍스트, 유형, 기본 모델 또는 출처별 모델 카탈로그 검색 |
| `search_nodes` | 텍스트, 카테고리 또는 입출력 유형별로 사용 가능한 노드 검색 |
| `cql` | 고급 디스커버리를 위한 Comfy Query Language 쿼리 실행 |

### 입력 및 체인링

| 도구 | 설명 |
|:-----|:------------|
| `upload_file` | 워크플로우에서 사용할 입력 이미지 또는 파일 업로드(예: LoadImage) |
| `use_previous_output` | 한 워크플로우의 출력을 다른 워크플로우의 입력으로 재사용하여 체인링 |

### 저장된 워크플로우

| 도구 | 설명 |
|:-----|:------------|
| `list_saved_workflows` | Comfy Cloud에 저장된 워크플로우 둘러보기 |
| `get_saved_workflow` | 저장된 워크플로우의 노드, 입력 및 구성 확인 |
| `save_workflow` | 워크플로우를 작업 공간에 저장(저장 또는 API 형식; API 형식은 자동 변환됨) |
| `run_saved_workflow` | 저장된 워크플로우를 가져와 API 형식으로 변환한 뒤 실행 제출 |

### 피드백(베타)

| 도구 | 설명 |
|:-----|:------------|
| `submit_feedback` | 평점과 댓글을 포함한 피드백 제출 |
| `report_session_summary` | 동의를 받은 세션 요약 보고(프롬프트, 파일 경로, 개인 정보 없음) |

<Info>
  서버는 워크플로우를 처음부터 만들기 전에 일치하는 미리 만들어진 템플릿을 확인하므로 더 나은 결과와 빠른 생성이 가능합니다.
</Info>

## 피드백

이것은 클로즈드 베타입니다—무엇이 잘 작동하는지 알려주세요.

- **에이전트 내:** `submit_feedback`(평점 + 댓글) 또는 `report_session_summary`(동의받은 세션 요약; 프롬프트/파일 경로/개인정보 없음)를 호출하도록 에이전트에게 요청하세요.
- **설문조사:** [links.comfy.org/cloudmcpbeta](https://links.comfy.org/cloudmcpbeta)
- **이슈:** 이 리포지토리에 제출하세요

도구 오류에는 세션당 한 번씩 해당 채널로 돌아가는 포인터가 포함되어 기억할 필요가 없습니다.

## 작동 방식

```
┌──────────────┐    HTTPS/MCP    ┌─────────────────────────────────────────────┐
│  AI 에이전트    │◄───────────────►│            Comfy Cloud                      │
│  (Claude,    │  API 키 또는     │  cloud.comfy.org/mcp → 워크플로우 실행   │
│   Cursor,    │  OAuth bearer   │                        on Cloud GPUs        │
│   Amp)       │                 │                                             │
└──────────────┘                 └─────────────────────────────────────────────┘
```

AI 에이전트는 `cloud.comfy.org/mcp`에 호스팅된 MCP 서버에 직접 연결합니다. 서버는 MCP 도구 호출을 Comfy Cloud GPU에서의 워크플로우 실행으로 변환합니다—로컬 서버나 GPU는 필요하지 않습니다.

파트너 모델의 경우, 에이전트는 일반적으로 `partner_generate`를 먼저 호출합니다(워크플로우 + 라이브러리 저장). 그 외의 경우는 디스커버리 도구(`search_templates`, `search_nodes`, `cql`)를 사용해 ComfyUI API 형식의 워크플로우 JSON을 작성하고 `submit_workflow`를 통해 제출합니다—자연어로 원하는 것을 설명하기만 하면 됩니다.

## 예제 프롬프트

설치 후, 다음 프롬프트를 AI 어시스턴트에서 시도해 보세요:

```
우주 공간에 떠 있는 만화풍 고양이 우주비행사 이미지 생성
```

```
텍스트-비디오 생성을 위한 워크플로우 템플릿 찾아줘
```

```
SDXL 체크포인트 모델을 검색하고 사용 가능한 모델을 알려줘
```

```
산과 석양 속 빛나는 강이 있는 판타지 풍경 생성
```

```

```

에이전트는 일치하는 템플릿을 검색하고 ComfyUI 워크플로우를 구성한 뒤 Comfy Cloud에 제출하고 대화 상에서 바로 생성된 이미지를 반환합니다.

## 출력 처리

- **이미지**는 대화 내에 인라인으로 표시되거나(Claude Code), 아티팩트 사이드 패널에 표시됩니다(Claude Desktop)
- **비디오 및 오디오** 출력은 다운로드 가능한 링크로 반환됩니다
- **애니메이션 이미지**(GIF, WebP)는 저장되지만 애니메이션을 유지하기 위해 인라인 미리보기는 제공되지 않습니다
- 인라인 이미지 미리보기는 효율적인 표시를 위해 1024px로 크기를 조정하며, 원본 해상도 출력은 항상 `get_output` 도구를 통해 이용 가능합니다

## 알려진 제한사항

<Warning>
  이것은 초기 버전입니다. 다음 제한사항들은 이미 알려져 있으며 적극적으로 개선 중입니다.
</Warning>

**워크플로우**
- **`run_saved_workflow` 적용 범위.** 이 도구는 저장된 워크플로우를 가져와 저장 형식→API 형식으로 변환한 뒤 제출합니다. 복잡한 입력 오버라이드나 지원되지 않는 노드가 포함된 워크플로우는 여전히 수동 수정 또는 `submit_workflow`를 통한 재구성이 필요할 수 있습니다.
- **워크플로우 메타데이터는 경로별로 다릅니다.** `partner_generate`의 출력물(워크플로우 경로)은 그래프가 내장된 상태로 자산 라이브러리에 저장되어 편집기에서 다시 열 수 있습니다. `submit_workflow` 또는 직접적인 `partner_generate` 백업 경로의 출력물은 자산 라이브러리에 전체 워크플로우 메타데이터가 포함되지 않을 수 있습니다.
- **워크플로우 정확성은 AI에 의존합니다.** 에이전트는 자연어로부터 ComfyUI 워크플로우를 구성합니다. 복잡한 다중 노드 워크플로우나 특이한 노드 구성은 반복이 필요할 수 있습니다.
- **`partner_generate` 범위.** 저장 가능한 모델에서 텍스트-이미지 생성은 저장된 워크플로우로 실행됩니다. 이미지 입력 생성, 매핑되지 않은 모델, 비이미지 모달리티는 워크플로우 저장 지원 확대 전까지 직접 프록시 백업(즉시 URL, 라이브러리 저장 아님)을 사용합니다.

**파일 처리**
- **업로드 크기 제한**은 MCP 클라이언트에 따라 적용될 수 있습니다.
- **이미지 미리보기는 크기가 조정됩니다.** 인라인 미리보기는 JPEG 기준 1024px로 제한됩니다. 원본 해상도 파일은 디스크에 저장됩니다.

**인증**
- **API 키 또는 OAuth.** 수동 설정에서는 `X-API-Key` 헤더에 Comfy Cloud API 키를 사용합니다. Comfy OAuth로 로그인하는 MCP 클라이언트는 `Authorization: Bearer` 토큰을 전송하며, 둘 다 호스팅된 서버에서 지원됩니다.

**클라이언트별**
- **Claude Desktop** — 생성된 이미지는 HTML을 통해 아티팩트 사이드 패널에 표시되며, 네이티브 이미지 아티팩트로 표시되지 않습니다.

## 문제 해결

### MCP 서버가 나타나지 않음

MCP 클라이언트를 재시작하세요(Claude Code, Claude Desktop, Cursor, Amp를 닫았다가 다시 열어주세요). MCP 서버는 시작 시 로드됩니다. 서버 URL이 구성에서 정확히 `https://cloud.comfy.org/mcp`인지 다시 확인하세요.

### API 키 오류

API 키가 유효한지 [platform.comfy.org/profile/api-keys](https://platform.comfy.org/profile/api-keys)에서 확인하세요. 수동 설정의 경우, `X-API-Key` 헤더에 키를 전달하세요—Bearer 토큰으로 `comfyui-` 키를 보내지 마세요. OAuth 연결 클라이언트는 Comfy 로그인 과정에서 받은 토큰을 사용해 `Authorization: Bearer`를 사용해야 하며, `X-API-Key`를 사용해서는 안 됩니다. 필요하다면 [새 API 키를 생성](https://platform.comfy.org/login)하고 클라이언트 구성에 업데이트하세요.

### 연결 오류

MCP 클라이언트가 서버에 접속할 수 없는 경우 다음을 확인하세요:
1. 인터넷 연결이 활성화되어 있는지
2. 방화벽이나 프록시가 `cloud.comfy.org`를 차단하지 않는지
3. 활성화된 [Comfy Cloud 구독](https://www.comfy.org/cloud/pricing?utm_source=docs&utm_campaign=cloud-api)이 있는지
